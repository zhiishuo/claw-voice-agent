# 空管移交协调规程摘录

## 移交前确认

航空器由一个管制席位移交至另一个管制席位前，移交管制员应当确认航空器呼号、当前位置、高度、速度、航向、许可限制以及后续管制意图。对于正在爬升、下降或者转弯的航空器，应当说明当前动态和已发布的限制条件。

## 移交通话要求

移交通话应当简洁、准确、完整。接收管制员复诵关键内容后，移交方方可结束协调。若接收方对高度、间隔、航路或者冲突风险存在疑问，应当立即追问并保持原管制责任不变，直到协调明确。

## 责任边界

在接收方明确接受之前，航空器仍由移交方承担管制责任。系统记录应保存移交时间、双方席位、航空器呼号和关键协调内容，便于运行复盘和安全审计。
